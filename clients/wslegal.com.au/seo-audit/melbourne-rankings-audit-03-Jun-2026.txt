ISSUE 1 — BROKEN INTERNAL LINKS (CRITICAL)
Pages: /property-lawyer-melbourne, /commercial-lawyer-melbourne
================================================================================

On the property lawyer Melbourne page, a sentence was pasted from Microsoft
Word and the internal links are attached to random mid-word fragments:

  ACTUAL HTML:

  <a href="property-lawyer-cranbourne">of residen</a>tial
  <a href="property-lawyer-narre-warren"> and commerc</a>ial property.

  This creates anchor texts: "se and", "of residen", "and commerc"

On the commercial lawyer Melbourne page:
  Anchor text: "al soli" → /commercial-lawyer-berwick

These are meaningless anchor texts that:
  (a) Tell Google nothing about the destination page
  (b) Signal low-quality content/spam-like behaviour
  (c) Are classic Word paste artefacts (note: class="MsoNormal" in the HTML)

WHY THIS MATTERS: Google uses anchor text as a relevance signal. Links to
Berwick/Cranbourne/Narre Warren pages should use suburb names as anchors.
Broken anchors actively hurt both the source and destination pages.

FIX: Rebuild these internal links in Squarespace using proper anchor text:
  "Purchase and sale of residential property in Berwick" → /property-lawyer-berwick
  etc. Never copy-paste from Word with existing hyperlinks.

ISSUE 2 — NO LOCAL BUSINESS SCHEMA ANYWHERE (CRITICAL)
All 6 pages + homepage
================================================================================

Every page on the site — including the homepage — has only this schema:

  {
    "@type": "WebSite",
    "url": "https://www.wslegal.com.au",
    "name": "Wollerman Shacklock Lawyers",
    "description": "",        ← BLANK
    "image": "..."
  }

What's missing:
  ❌ No LocalBusiness or LegalService schema (Google can't understand it's a law firm)
  ❌ No address, phone, geo coordinates
  ❌ No opening hours
  ❌ No service area
  ❌ Empty description field
  ❌ No Attorney type schema

This is significant. Every competitor ranking for "commercial lawyer melbourne"
or "probate lawyer melbourne" will have LegalService or LocalBusiness schema
specifying their location, service area, and services. Google uses this to
assess relevance for local searches.

FIX: Add LegalService + LocalBusiness schema via Squarespace Code Injection.
Suggested schema for each Melbourne page:

  {
    "@context": "https://schema.org",
    "@type": ["LegalService", "LocalBusiness"],
    "name": "Wollerman Shacklock Lawyers",
    "description": "Specialist property, commercial and estate lawyers serving Melbourne and South-East Victoria.",
    "url": "https://www.wslegal.com.au",
    "telephone": "(03) 9707 1155",
    "email": "admin@wslegal.com.au",
    "address": {
      "@type": "PostalAddress",
      "streetAddress": "[Street]",
      "addressLocality": "Narre Warren",
      "addressRegion": "VIC",
      "postalCode": "[Postcode]",
      "addressCountry": "AU"
    },
    "areaServed": ["Melbourne", "Casey", "Narre Warren", "Berwick", "Cranbourne"],
    "priceRange": "Fixed fee",
    "openingHours": "Mo-Fr 09:00-17:00"
  }

Note: On Squarespace, add this via Settings → Advanced → Code Injection →
Page Header (use per-page injection for the Melbourne service pages).

ISSUE 3 — PHYSICAL LOCATION vs. SEARCH INTENT (HIGH — STRUCTURAL)
All 6 Melbourne pages
================================================================================

This is the hardest issue and the primary reason for non-rankings.

Wollerman Shacklock is physically located in Narre Warren (SE Melbourne suburbs).
When a user searches "conveyancer melbourne" or "commercial lawyer melbourne",
Google's local algorithm heavily favours businesses:
  (a) With a Melbourne CBD or inner-suburb address on their Google Business Profile
  (b) With strong Melbourne location signals across the web

Firms ranking for these terms will typically be located in or near the CBD —
Carlton, Richmond, Southbank, Fitzroy, St Kilda Rd.

Impact per keyword:
  "conveyancer melbourne"             → High local intent. Very hard without CBD presence.
  "commercial lawyer melbourne"       → High local intent. Hard.
  "commercial lease lawyer melbourne" → Moderate. More achievable via content depth.
  "property lawyer melbourne"         → High local intent. Hard but more achievable via Accreditation authority.
  "probate lawyer melbourne"          → Moderate. Lower local intent, more informational.
  "wills and estates lawyer melbourne" → Similar to probate. More achievable.

WHAT TO DO:
  Option A: Build Melbourne-specific content authority over time (slower, 6-12 months).
  Option B: If the firm has any Melbourne-area meeting capacity, set up a secondary
            GBP listing with a serviced office address in Melbourne CBD.
  Option C: Shift targeting to "south-east melbourne [keyword]" and "casey [keyword]"
            where competition is lower and the physical proximity works in their favour.
  Option D: Continue targeting Melbourne but manage client expectations — these terms
            take 9-18 months to crack without a Melbourne address.

Note: The Casey/Narre Warren-targeted pages (property-lawyer-pakenham,
property-lawyer-berwick etc.) are more likely to rank quickly and deliver
actual client enquiries. Don't neglect these for Melbourne chasing.

ISSUE 4 — NO FAQPage SCHEMA (HIGH)
Pages with FAQ sections: ALL 5 service pages (not conveyancer)
================================================================================

Five of the six pages have FAQ sections but zero FAQPage schema markup.

Pages with FAQ sections (confirmed):
  ✓ /property-lawyer-melbourne
  ✓ /wills-estate-planning-melbourne
  ✓ /probate-lawyer-melbourne
  ✓ /commercial-lawyer-melbourne
  ✓ /commercial-lease-lawyer-melbourne
  ✗ /conveyancer-melbourne (has FAQ heading, minimal content)

FAQPage rich snippets:
  - Appear directly in Google SERP (expanded Q&A under the listing)
  - Significantly increase SERP real estate and CTR
  - Help Google understand question-based search intent
  - Especially powerful for law queries ("how much does probate cost melbourne")

FIX: Add FAQPage schema to each page via Code Injection. Example structure:
  {
    "@context": "https://schema.org",
    "@type": "FAQPage",
    "mainEntity": [
      {
        "@type": "Question",
        "name": "How much does probate cost in Melbourne?",
        "acceptedAnswer": {
          "@type": "Answer",
          "text": "..."
        }
      }
    ]
  }
