# Content Plugin — Client Folder

This folder is managed by the `content` plugin. When you enter this folder, you are working on content for **globallocksmiths.com.au**.

## How to interact

Just type naturally. The agent understands intents like:
- "add a note that they want more commercial focus"
- "what's the status?"
- "research the location keywords"
- "generate the richmond AC page"
- "lock the service-location plan"
- "export everything as markdown"
