## Getting to the Keypad Past the Security Door

Once a security door goes on, two locks sit between you and the hallway, and a keypad changes the second one rather than the first. The screen still opens with its own key or latch. What changes is that nothing has to be found in a pocket at the main door.

Mesh is the part most people have not thought about. On a woven stainless or perforated aluminium screen you cannot press a keypad through it, and a fingerprint reader needs skin on the sensor. So on most security doors the screen opens first and the code goes in second.

Reach decides the rest. A security door swings out toward you, so you step back to let it clear, then forward again to the keypad. Where the screen's own lock sits on the same side as the new one, both get used in the same narrow space, often with the shopping in your other hand.

## How Much Room Is Between the Screen and the Door

Open the screen and look at the space it leaves against the main door. A smart lock takes up more of that space than the knob it replaces, because the outside half, the part carrying the keypad or the reader, stands proud of the door face. Where a security door closes tight with little air behind it, that projection decides whether the screen still shuts.

So the clearance is measured with both leaves closed, at the lock stile and again on the hinge side. A lever on the main door and a pull handle on the screen can end up fighting for the same few centimetres.

If the security door is still to come, mention it anyway. A made-to-measure screen and the lock you choose have to agree on that clearance, and choosing hardware that suits both beats sorting out a clash afterwards.

## Screen Doors, Keypads and the Rest of the House

### Can I use the keypad without opening the security door first?

Not through the mesh. A woven or perforated screen blocks a keypad and covers a fingerprint reader, so on most security doors the screen opens first and the code goes in second. The gain is that the second step no longer needs a key.

### Should the smart lock go on the security door or the one behind it?

Almost always the one behind it. A smart deadbolt or smart mortice lock is built around a solid leaf with a stile wide enough to carry the lock body, and a security door's frame is narrower than that. Security doors take their own hardware range.

### We have four external doors. Do they all need smart locks?

No. One keypad at the main entry with the rest rekeyed to a single key covers most houses. If a back or side door earns a keypad of its own, it is quoted as its own line rather than assumed.

### How long does it take to install a smart lock?

It depends on what is already in the door. Dropping a lock into a bore that suits it is quick, while preparing a door that has never carried one takes longer. A security door in front adds a step at the end, since the sequence gets checked with both leaves closing.
