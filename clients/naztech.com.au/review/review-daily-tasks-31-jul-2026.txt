--- 3D. HTML CODE ---------------------------------------------------------------

  3.15 DUPLICATE ELEMENT IDs ON 45 PAGES                  [ MEDIUM ]
       Every page carrying two enquiry forms (hero + footer) outputs the same
       four IDs twice:
         form-field-name, form-field-field_f5ff1b5, form-field-email,
         form-field-message
       Duplicate IDs are invalid HTML. Practical consequence: <label for=...>
       resolves to the first field only, so tapping a label on the second form
       focuses the wrong input, and screen readers announce it wrong.
       FIX: Elementor lets you set a custom ID per form — give the second form
       a distinct prefix.

  3.16 FOUR DIFFERENT tel: LINK FORMATS SITEWIDE          [ MEDIUM ]
         tel:0449%20992%20695   — 403 instances  (URL-encoded spaces)
         tel:+61449992695       — 123 instances  (correct E.164 format)
         tel:0449992695         — 110 instances
         tel:0449 992 695       —  61 instances  (raw space — invalid URI)
       The raw-space variant is malformed and can fail to dial on some Android
       browsers and in-app webviews.
       FIX: standardise everything on tel:+61449992695.

  3.17 EMPTY ANCHOR WITH NO ACCESSIBLE NAME — 49 PAGES    [ MEDIUM ]
       The header phone-icon link (<a href="tel:0449992695">) has no link text
       and no aria-label. Screen readers announce it as "link" with no target.
       FIX: add aria-label="Call NAZTECH on 0449 992 695".
